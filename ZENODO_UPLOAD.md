# Zenodo upload checklist

1. Create the GitHub repository `simonator420/rsm-individual-heterogeneity` and push this repository.
2. Create a Git tag and GitHub release named `v1.0.0`.
3. Enable the repository in Zenodo and archive the `v1.0.0` release.
4. Check the imported metadata against `.zenodo.json` and `CITATION.cff` before publishing.
5. After the associated article receives a DOI, add that DOI to the Zenodo record as a related publication.

The repository is intentionally limited to reproducibility materials. Upload the manuscript, title page, cover letter, and submission figures separately through the journal submission system rather than adding them here.
