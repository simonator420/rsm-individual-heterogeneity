# Data

`pone.0219295.s001.csv` is the public supplementary CSV associated with:

Wu PP-Y, Sterkenburg N, Everett K, Chapman DW, White N, Mengersen K. (2019).
*Predicting fatigue using countermovement jump force-time signatures: PCA can
distinguish neuromuscular versus metabolic fatigue.* PLOS ONE, 14(7), e0219295.

Source DOI: <https://doi.org/10.1371/journal.pone.0219295.s001>

The data are anonymized and were publicly released with the source article.
Please retain the source article attribution and license information when
redistributing the repository.
